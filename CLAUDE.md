# glimr

Shareable 2000s-style 3D personal rooms. Milestone 1 is a local-only room with a CD shelf you can play music from.

## Commands

Node 22 (`.nvmrc`).

- `npm run dev`
- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build`

## Stack

Vite + React 19 + React Compiler + React Three Fiber 9 + drei + zustand + zod + Vitest.
